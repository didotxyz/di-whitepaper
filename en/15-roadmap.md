# 14. Product Roadmap

DI plans to launch its initial products before TGE, then expand quantitative and API capabilities and develop Personal Agents and their network. These are planned release stages; development completion does not mean a service is already publicly available.

| Stage | Timing / dependency | Focus |
| --- | --- | --- |
| 01 Initial product launch | Before TGE | Data Dashboard, Event Engine, in-house quantitative strategies, strategy tools and paid professional data API access |
| 02 Product expansion and Personal Agents | After initial launch | Expand strategy coverage, tools and API capacity; connect data, simulation and quant capabilities around ongoing user tasks |
| 03 First Agent network | Seed-user phase | Establish an interconnected network with seed users from 2,000 founding NFTs |

## 01 Initial product launch

The planned initial offering includes the Data Dashboard, Event Engine, in-house quantitative strategies, strategy tools and paid professional data API access. These products are planned to launch before TGE. Paid API access is included from the first paid month; later API milestones expand coverage and capacity rather than introduce charging for the first time.

Product development provides the foundation for launch. Availability is determined by the services formally opened to users.

## 02 Product expansion and Personal Agents

After the initial launch, DI plans to expand quantitative strategy coverage, strategy tools and professional data API coverage and capacity. Later quantitative milestones refer to these extensions, not the first release of in-house strategies or tools.

DI will connect data, simulation and quant capabilities through Personal Agents, using user preferences to monitor markets and work on financial tasks.

The focus moves from individual operations to ongoing work: retaining research context, using new information to support further analysis and connecting products under user authorization.

## 03 The first Agent network

Seed users from 2,000 founding NFTs will form the first network. Their Agents will exchange information, call capabilities and collaborate on tasks.

Seed users from the founding NFTs will participate in early network development, exchanging information and combining capabilities around real tasks.
