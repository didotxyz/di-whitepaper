# 14. 产品发展 Roadmap

DI 计划先在 TGE 前上线首期产品，随后扩展量化与 API 能力，并发展个人 Agent 及其网络。以下为计划中的发布阶段；完成产品构建不代表服务已经对外开放。

| 阶段 | 时间／触发条件 | 主要内容 |
| --- | --- | --- |
| 01 首期产品上线 | TGE 前 | 数据看板、Event Engine、自研量化策略、策略工具及收费专业数据 API |
| 02 产品扩展与个人 Agent | 首期上线后 | 扩展策略覆盖、工具与 API 容量，连接数据、推演和量化能力以处理持续任务 |
| 03 首个 Agent 网络 | 种子用户阶段 | 以 2,000 个创始 NFT 对应的种子用户形成首个互通网络 |

## 01 首期产品上线

首期计划提供数据看板、Event Engine、自研量化策略、策略工具及收费专业数据 API，并在 TGE 前上线。收费 API 从首个付费月开始提供；后续 API 阶段扩展覆盖范围和容量，不作为首次开放收费的时间。

产品构建为上线提供基础，具体可用功能以正式向用户开放的服务为准。

## 02 产品扩展与个人 Agent

首期上线后，DI 计划扩展量化策略覆盖、策略工具及专业数据 API 的覆盖范围与容量。后期量化里程碑指能力扩展，不是自研策略和工具首次上线。

DI 将把数据、推演和量化能力连接到个人 Agent，结合用户偏好，持续跟踪市场并处理金融任务。

重点从单次操作转向持续任务：保留研究上下文，利用新信息开展进一步分析，并在用户授权下衔接不同产品。

## 03 建立首个 Agent 网络

以 2,000 个创始 NFT 对应的种子用户建立首个网络，让这些用户的 Agent 交换信息、调用能力和协作完成任务。

创始 NFT 对应的种子用户将参与初期网络建设，围绕真实任务建立信息交换与能力协作。
