# 13. DI Token 用途

$DI 在产品路线图中有三项用途。

| 用途 | 使用方式 |
| --- | --- |
| 支付推演与策略服务 | 用户可用 $DI 支付 Event Engine 推演和付费策略服务。按产品规则，持有 $DI 即可使用基础数据看板及部分自有策略。 |
| 奖励有效贡献 | 对于经 DI 验证、对模型或产品有实际价值的数据、研究及其他贡献，贡献者可获得 $DI 奖励。 |
| 支付 Agent 间研究服务 | 在未来的网络中，一个 Agent 可用 $DI 向另一个 Agent 支付研究或分析任务的费用。 |

DI 计划以自身部分业务利润回购并销毁 $DI。可用于回购的资金不含用户本金及应付用户收益。支付服务费本身不会销毁代币。
